# 📚 Atlas Visual - Monorepo

Repositório centralizado de páginas de vendas dos Atlas Visuais.

## 📁 Estrutura de Projetos:

- **`atlas-ultrassonografia/`**: Página de vendas do Atlas Visual da Ultrassonografia.
- **`atlas-microbiologia/`**: Página de vendas do Atlas Visual de Microbiologia de Alimentos.

---

## ⚡ Como Configurar no Vercel:

### 1. Projeto: Atlas Ultrassonografia
- **Vercel Project Name:** `atlas-ultrassonografia`
- **Framework Preset:** `Other`
- **Root Directory:** `atlas-ultrassonografia` (ou selecione a pasta)
- **Output Directory:** `public` (configurado automaticamente pelo vercel.json)

### 2. Projeto: Atlas Microbiologia
- **Vercel Project Name:** `atlas-microbiologia`
- **Framework Preset:** `Other`
- **Root Directory:** `atlas-microbiologia` (ou selecione a pasta)
- **Output Directory:** `public` (configurado automaticamente pelo vercel.json)
